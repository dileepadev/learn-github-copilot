# Contributing to Learn GitHub Copilot

Thank you for your interest in contributing! This project is designed to explore and demonstrate the capabilities of GitHub Copilot, and community contributions are what make it better.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion, please [open an issue](https://github.com/dileepadev/learn-github-copilot/issues) with a clear description.

### Adding Examples

New examples are always welcome. When adding an example:

1. Place it in the appropriate language directory under `examples/`
2. Add a comment at the top of the file explaining what Copilot capability it demonstrates
3. Keep examples focused and well-commented so readers understand the intent
4. If possible, include a test file alongside your example

### Submitting Changes

1. Fork the repository
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Commit with a clear message: `git commit -m "Add example demonstrating X capability"`
5. Push to your fork and open a Pull Request

## Code Style

- **Python**: Follow [PEP 8](https://peps.python.org/pep-0008/)
- **JavaScript**: Use consistent indentation (2 spaces)
- Add comments explaining what GitHub Copilot was prompted with or how the code was generated

## Ideas for Contributions

- Examples in additional programming languages (Go, Java, C#, Rust, etc.)
- More advanced use cases (e.g., API integrations, data processing)
- Exercises and challenges for learners
- Tips and tricks for getting better suggestions from Copilot
